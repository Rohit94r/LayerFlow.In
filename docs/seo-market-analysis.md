## 3. Competitor matrix

Audience: **E** = eng/prod AI apps · **I** = individuals/power users · **T** = teams/enterprise.

| Site | Audience | Core features | Pricing angle | SEO strengths | Gaps LayerFlow can own |
|------|----------|---------------|---------------|---------------|------------------------|
| **LangSmith** | E/T | Tracing, evals, Prompt Hub, LangChain depth | Seat + usage; free developer tier | “LangChain observability”, evals, Prompt Hub | Not a personal prompt workspace; hard for non-LangChain / non-devs; no consumer “save my ChatGPT prompts” story |
| **Langfuse** | E/T | OSS tracing, prompt mgmt, evals, self-host | Free self-host; cloud metered | Open-source LLM observability | Engineer UX; not daily workspace for writers/students; no hard consumer budget story |
| **PromptLayer** | E/T | Prompt CMS, visual edit, registry, tests | SaaS for product teams | Prompt management + PM workflows | Still product-team; weak “everyone’s AI workspace” + hard personal budgets |
| **Portkey** | E/T | Gateway, routing, guardrails, budgets, logs | Free → ~$49 prod logs → enterprise (Palo Alto) | “AI gateway”, enterprise governance | Infra-first; complex; not prompt Timeline/Sessions for humans |
| **OpenRouter** | E/I | Multi-model API marketplace, credits, BYOK option | Pay-as-you-go credits / fee | Model discovery, “one API many models” | No prompt org; spend visibility ≠ hard workspace budgets + compare UX |
| **LiteLLM** | E | OSS proxy, virtual keys, budgets | Free self-host + ops cost | Self-host gateway, GitHub SEO | No polished workspace; DIY; not for marketers/students |
| **Helicone** | E | Observability gateway, cost logs | Free tier + SaaS; Mintlify acquisition / transition risk | LLM logging, cost dashboards | Observability not workspace; product trajectory uncertain |
| **Braintrust** | E/T | Evals, traces, playground, scoring | Free → **~$249/mo Pro** | Eval + cost-in-prod content | Price wall for individuals; eval-first not “organize my life with AI” |
| **Humanloop** | E/T | Prompt eng + evals | Sunset / team → Anthropic (verify) | Historical prompt tooling SEO | Opportunity: capture displaced searchers with migration content |
| **ChatGPT Teams / Plus** | I/T | Chat, Custom GPTs, memory | ~$20–$30/user | Enormous brand SEO | Locked to one vendor; weak multi-model compare; no hard cross-provider budgets; prompts trapped in history |
| **Notion AI** | I/T | Docs + AI in Notion | Seat-based Notion plans | Productivity SEO | Copy-paste friction into ChatGPT/Claude; no model compare/cost enforcement |
| **Cursor / IDE prompt tools** | E | In-editor AI | Editor subscription | Coding workflow | Coding-only; not cross-domain prompt library + budgets for all AI work |
| **Snippet tools** (TextExpander, Raycast, Typinator) | I | Instant insert everywhere | Per-seat / one-time | “prompt expander”, Mac productivity | No version/cost/compare/gateway; LayerFlow should **integrate** not replace |

### Top 3 competitor gaps to own (priority)

1. **Human AI workspace (not observability)** — Domains → Projects → Timeline → Sessions; works for marketers, students, agencies, solo founders — not just LangChain apps.
2. **Hard budgets that block spend** — Especially for individuals and small teams who fear OpenAI/Anthropic invoice shock; pair with “could have saved $X with Auto Mode.”
3. **Always-available capture + insert** — Browser extension / CLI / Raycast so users don’t live in Notion copy-paste or ChatGPT history (competitors leave this to TextExpander-class tools).

## 5. Always-available product bets (ranked)

Surfaces so users don’t need to open layerflow.dev every time.

| Rank | Bet | Why | MVP scope (2–6 weeks each) |
|------|-----|-----|----------------------------|
| **1** | **Browser extension** (Chrome/Edge) | Highest everyday friction: ChatGPT/Claude/Gemini tabs. Features.md deferred extension for growth — now it’s the #1 retention surface. | Save selection → LayerFlow prompt; inject template; optional “compare” deep-link; one-click BYOK run later |
| **2** | **Weekly email digest** (already in Module 2) | Soft always-on; ships with Cost Manager; drives return visits | Spend, top prompts, budget remaining, 1 savings tip, CTA to flagged prompts |
| **3** | **CLI (`lf`)** | Devs live in terminal; complements gateway | `lf save`, `lf run`, `lf budget`, `lf compare`; auth via device code |
| **4** | **Raycast / Alfred / Spotlight-style** (or Cursor command) | Snippet-class speed without becoming TextExpander | Search library, paste variables, open compare |
| **5** | **Slack bot** (then Discord) | Teams already paste prompts in Slack | `/lf save`, `/lf budget`, weekly channel digest |

**Park for later:** WhatsApp bot (auth/privacy harder), desktop tray (overlap with Raycast), full VS Code/Cursor extension (high value but heavier than CLI+extension).
