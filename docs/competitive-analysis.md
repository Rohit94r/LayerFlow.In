# Competitive Analysis — AI Workspace Landscape

## The Gap
Existing tools are either:
1. **Infrastructure-focused** (Portkey, LiteLLM, LangSmith) — built for engineering teams, complex SDKs
2. **Expensive** (Braintrust at $249/mo, Portkey enterprise)
3. **Not designed for prompt organization** — they do observability/routing, not workspace management

## Competitors

### LangSmith (LangChain)
- Dominant in observability + evaluation
- Deep LangChain ecosystem lock-in
- Enterprise-focused (SOC2, SSO, BYOC)
- NOT a prompt workspace — it's an observability/debugging platform

### Portkey (Acquired by Palo Alto Networks)
- AI Gateway + Observability + Guardrails
- 300B+ tokens/day before acquisition
- Enterprise pricing, complex feature set
- NOT a prompt workspace

### LiteLLM
- Open-source AI Gateway
- 53.8K GitHub stars, YC W23
- Used by Stripe, Netflix
- Pure gateway — no workspace, no prompt management

### Helicone (Acquired by Mintlify)
- LLM observability
- Exited/acquisition — no longer actively developed

### Braintrust
- AI observability + evals
- $249/mo starting price
- Evaluation-focused, not prompt workspace

## Our Position
LayerFlow occupies a **new category**: AI Workspace for Prompts.

Not competing with:
- LangSmith on observability
- Portkey on gateway
- LiteLLM on open-source proxy

Competing on:
- Prompt organization & versioning
- Multi-model comparison
- Cost management for individuals and teams
- Simplicity — works for non-developers too

## Market Opportunity
- 2024-2025: Companies building AI apps
- 2026: Everyone uses AI daily
- Everyone has prompts, AI history, reusable workflows — nobody manages them
- Reddit complaints: "I lost my best prompt" / "I don't remember which model worked" / "My team shares prompts in Slack"

## Key Insight
The product isn't AI Gateway.
The product is AI Workspace.
Like GitHub for code → LayerFlow for prompts.
