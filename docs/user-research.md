# User Research — Prompt Management Pain Points

## Common Complaints (from Reddit, X, AI communities)
1. "I lost my best prompt."
2. "I don't remember which model worked."
3. "I wasted $40 testing GPT."
4. "I need version history."
5. "My team shares prompts in Slack."
6. "I have 200 prompts scattered everywhere."
7. "I don't know which prompt is latest."
8. "I copied the wrong prompt."

## User Personas

### Developer
- Builds AI features into apps
- Needs: prompt versioning, model comparison, cost tracking
- Currently: stores prompts in code comments, Notion, or nowhere

### Student / Learner
- Learning prompt engineering
- Needs: save prompts, track what works, compare models
- Currently: ChatGPT history, Claude conversations, no organization

### Marketer / Content Writer
- Uses AI for copywriting, SEO, email campaigns
- Needs: organized prompt library, version history, team sharing
- Currently: Google Docs, Notes app, Slack messages

### Agency
- Manages prompts for multiple clients
- Needs: project organization, client-specific libraries, cost tracking
- Currently: chaotic — Notion, shared drives, WhatsApp

### Researcher
- Tests hypotheses across models
- Needs: prompt versioning, output comparison, analytics
- Currently: scattered notes, multiple browser tabs

## What Users Want
- Simple prompt organization (projects + folders)
- Version history with diff
- Side-by-side model comparison
- Cost tracking per project
- Team sharing
- Export/import prompts
- Free tier for personal use

## What Users DON'T Want
- Complex SDKs
- Enterprise security features they don't need
- Yet another gateway/proxy
- Expensive team plans for solo use
